# HA 家庭控制

执行 `python3 scripts/close_lamp.py`，通过参数控制；不得自行构造网络接口或修改脚本。
只控制本技能 catalog 返回的设备，不操作锁、空调、插座等其他设备。

## 先识别实际设备

1. 每次新的控制意图先调用 `--command catalog` 获取当前名称、区域、实体 ID、kind、能力与状态。目录和查询不会控制设备。
2. 根据用户说的名称和房间匹配目录中的设备。优先使用返回的 entity_id 执行。不得猜测实体 ID。
3. 多个匹配、用户只说“这个灯”、或“关到30%”含义不明确时，列出候选并向用户澄清，不执行控制。
4. “客厅的灯”“客厅所有灯”表示该房间灯组，用 `--domain light --area 客厅 --all`；“客厅主灯”则选单个实体。
5. “所有灯”使用 `--domain light --all`；“所有窗帘”使用 `--domain cover --kind curtain --all`，不包含晾衣架。只有用户明确要求全部窗帘与晾晒设备时才包含晾衣架。

## 指令映射

统一使用 `--command control`，目标用 `--entity-id <目录中的ID>`，或上面的显式分组参数。

| 用户意图 | 参数 |
|---|---|
| 开灯 / 关灯 | `--action turn_on` / `--action turn_off` |
| 亮度50% | `--action brightness --value 50` |
| 色温4000K | `--action color_temperature --value 4000` |
| 开帘 / 关帘 / 停止 | `--action open` / `--action close` / `--action stop` |
| 开合度50% / 开一半 | `--action position --value 50` |
| 晾衣架上升 / 下降 / 停止 | `--action open` / `--action close` / `--action stop` |
| 晾衣架高度80% | `--action position --value 80` |

开合度0为全关、100为全开。晾衣架使用页面已校正的实体：0为最低、100为最高；不得绕过该实体反转方向。
仅执行目录 actions 中列出的能力，亮度和位置的值为0至100整数；亮度0表示关灯。色温遵守目录返回的上下限。
对于灯组调光，不能调光的灯会返回不支持，向用户说明这些设备未调节，不假报全部成功。

## 返回与状态查询

- 命令输出为JSON。控制返回 accepted 只表示HA已接收，回复“已发送指令”；不能只凭HTTP成功就说窗帘已到位。
- 用户要求状态，或需要核实完成时，使用 `--command status --entity-id <ID>`；分组查询同样可用 `--domain light --area 客厅 --all`。
- 对离线、歧义、不支持、部分失败等结果如实说明；展示设备名称，不向用户展示内部接口或凭据。
- 超时后的执行状态可能未知。先查询，不能自动重发控制。脚本仅重试无控制GET连接检查，POST从不自动重试。
- 不打印、读取给用户或回显 settings.json 中的接口地址及密钥。

保留标识 close-desk-lamp 以兼容现有测试组；功能已扩展为家庭控制。无参数执行仅兼容原有“关闭台灯”，通常应按上述显式参数调用。
